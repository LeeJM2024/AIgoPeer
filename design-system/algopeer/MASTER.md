# AlgoPeer · 算法演算场设计系统

生效：2026-10-16。用户已确认蓝白渐变与曲线容器，并要求把该方向落到实际登录页、学生端、教师端。此文替代旧的“课程档案夹 / 深青导航 / 不用渐变 / 4px 控件”规范。

## 构图

入口是一张会演算的大学课程海报；内页是清晰紧凑、有课程内容视觉的工具。

- 登录桌面：34% 表单 + 66% 大标题与归并结构。横屏时“写出解法”“讲清思路”并排一行，说明文字也为一行；竖屏时标题和说明各保留两行。手机先标题、再表单、再算法画面；登录操作仍在首屏内可达。
- 公共框架：水平角色导航，账号与退出入口不变，学生评审入口仍受真实任务资格控制。
- 学生端：当前最需处理的作业展开，其他作业连续列表；待办和相关课程插画在侧栏，窄屏下移。
- 教师端：真实指标、接下来处理、最近作业与具体作业封面。无重复课程宣传横幅。
- 操作页：材料与表单为主体，相关算法图适量参与；不能拿通用插图冒充学生作品或题目样例。

系统字体：Segoe UI、PingFang SC、Microsoft YaHei、system-ui。不额外请求联网字体。登录横屏大标题按海报内容宽度缩放（11cqi，上限 112px）；竖屏平板 72–112px，手机 48–64px；工作台标题 27–34px。真实代码使用等宽字体，数字使用 tabular-nums。

主容器 26–38px 圆角，局部使用 64–120px 不对称大弧角；控件通常 12–16px。不把每个标签和每段内容各装一个盒子。渐变为用户明确选择，优先于设计技能的默认“平色/方角”偏好。表面用明度层次区分，不堆静态阴影和发光效果。

## 图片与动效

全站登录、注册、教师端、学生端与评审页面共用 `BrandLogo`，统一使用用户提供的“华中科技大学 网络空间安全学院”原图，保留透明度和 302:71 比例，以 `brightness(0)` 显示为纯黑。桌面宽 240px，手机宽 `min(44.5vw, 192px)`。源文件为 `frontend/src/assets/hust-cse-logo.png`，不重绘校徽或文字，不再保留旧 AlgoPeer 图形标识分支；页脚及浏览器标题同步使用校院名称。项目内部代码、接口和认证标识不做品牌改名。

`AlgorithmArtwork.vue` 使用 `buildMergeTimeline` 的真实稳定归并轨迹；每帧保留数字身份、对应结构位置与代码行。自动演算一次结束，不无限循环。控制提供暂停、下一步、重新演算，减少动态效果下仅保留手动操作。离开视口、页面隐藏时停止定时推进；卸载清除计时和监听。

`AssignmentArtwork.vue` 按实际标题/知识点生成归并、背包、图、树、整数求和或代码主题插画，微课项目另有讲解材料封面。没有相关主题则用一般代码，不把任意作业包装成归并。图片标注仅为课程示意，不当作题目测试或学生材料。评分区保留真实视频、代码、说明文件预览。

## 交互、可访问性、状态

- 使用真实链接、按钮、持久标签、可见键盘焦点。主要控制至少 44px；不依赖悬停才能操作。
- 错误、加载、空状态分开；失败可以重试，不虚构统计或进度。
- 状态含文字，缺失分数与零分区分；不提前展示未发布成绩。
- 导航换行，不挤出手机页面；表格可在自身容器内滚动，代码可独立滚动，长标题可换行。
- 页面切换与数字移动仅变换 transform/opacity；尊重 prefers-reduced-motion。
- API、认证、权限、匿名边界、截止与评分发布规则不变。五人评分未齐继续等待，高风险由同一位教师查看完整证据后填写最终分与理由。
