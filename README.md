# AlgoPeer

AlgoPeer 是面向《算法设计与分析》课程的作业与跨班评审平台，连接作业发布、学生提交、自动判题、匿名互评、教师复核与成绩反馈。

学生可以完成编程练习、在线作答和期末微课，向 AI 助教提问，并在系统分配的匿名任务中参与评阅。教师可以管理课程班级、追踪学习过程、配置评审与成绩规则，并结合原始材料和异常证据确定最终成绩。

## 功能概览

| 功能 | 使用方式 |
| --- | --- |
| 课程与作业 | 管理班级、学生和知识点；发布编程题、算法分析题、证明题、开放问答及期末微课 |
| 编程练习 | 提交 C++17 程序，查看判题结果、编译反馈和提交历史 |
| 在线作答 | 算法分析、证明和开放问答直接填写答案，提交即完成，保留历次版本 |
| 期末微课 | 按所属大章和知识点选题，上传 PPT、讲解视频、代码与测试材料 |
| 跨班匿名评审 | 每份有效作品由对方班五名不同学生评阅，系统统一分配任务 |
| 可信成绩 | 稀疏贝叶斯模型校准同伴评分；教师处理异常、完成最终复核后发布 |
| 学习分析 | 查看提交情况、常见错误、通过率和知识点学习证据 |
| AI 辅助 | 编程辅导、知识点问答、教学建议，以及带时间点证据的视频辅助评阅 |

期末微课的教师分与同伴聚合分默认按 60% / 40% 合成，教师可在发布作业前调整比例。高风险作品由同一位教师查看完整证据后录入一个复核最终分。完整规则见[算法设计](docs/算法设计.md)。

## 本地体验

准备 Docker Compose、Node.js 20 或更高版本。在仓库根目录复制配置并启动服务：

```powershell
Copy-Item .env.example .env
# 编辑 .env，设置数据库密码、独立的 JWT_SECRET 和 INTERNAL_API_TOKEN。
docker compose up -d --build
docker compose exec backend python scripts/seed_demo.py
```

在另一个终端启动前端：

```powershell
cd frontend
npm ci
npm run dev
```

打开[本地登录页](http://localhost:5173/login)。初始化脚本为本地体验创建教师 `T001`、学生 `D101`～`D110` 和 `D201`～`D210`，初始密码均为 `AlgoPeer2026!`。这些账号仅用于演示，正式环境的账号由课程管理员和教师准备。

学生账号由教师统一添加或导入。登录后可在右上角修改密码。上传功能可使用[材料样例](samples/README.md)体验。

## 正式部署

正式服务通过 HTTPS 域名提供前端和 API，使用独立的生产数据库、材料存储及密钥。仓库提供 `docker-compose.production.yml` 部署数据库、Redis 和后端；前端静态站点和独立判题 worker 的配置见[部署与运维](docs/部署与运维.md)。
