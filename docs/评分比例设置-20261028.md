# 教师配置评分比例

期末微课、算法分析、证明、开放问答作业默认教师评分占60%、同伴评审占40%。教师在新建或编辑草稿时，可通过“成绩组成”设置两项百分比，单项范围0%～100%，支持两位小数，合计必须为100%。

保存草稿后保留实际设置，发布作业后冻结。详情页展示本次作业比例。普通作品的最终分按作业保存的权重计算，并在发布成绩时保存权重快照。例如教师90分、同伴聚合80分，70%/30%得到87分。

HIGH作品仍由教师复核给出最终分。即使同伴权重设为0%，仍须按既有流程完成五份有效评审和异常处理。编程作业继续自动判题。

数据库迁移`20261028_0012`移除固定60/40约束，保留权重合计校验、发布后冻结、异常处理与成绩快照校验，不改写现有作业或成绩。若存在自定义比例，降级会停止，以保留其原始设置。

针对性验证包括默认值、自定义比例与小数、无效输入拦截、草稿编辑回填、数据库约束、70/30与两个端点的实际计分，以及发布后冻结。
