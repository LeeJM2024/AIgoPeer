# 作业管理与提交评审并行

## 教师操作

- 作业列表和详情页提供关闭、恢复、删除，适用于已发布作业及已公布成绩的作业。
- 关闭暂停学生提交与评审；恢复按原有阶段和截止时间继续，不延长原截止时间。
- 删除从师生正常入口移除，旧链接不可访问。数据库保留原始记录与审计，不改写已公布成绩。
- 教师无需等待提交截止即可按当前有效提交生成任务。生成评审任务不结束提交。
- 后续新作品提交后，教师刷新名单并再次生成任务，只追加新增作品的评审任务，保留已有任务、评分及其身份。
- “结束提交”单独停止接收新作品及新版本，评审继续进行。自然提交截止也会停止接收。
- 汇总前先结束提交、补齐新增作品的任务和评分；每份作品五份有效评分的要求保持。

## 学生操作

尚未分配评审的作品，可以在提交开放时提交或修改。已分配评审的作品锁定当前版本，可查看材料和历史。学生评委只访问自己的任务，已提交评分保持。

## 分配方法

首次分配沿用联合整数优化，每份五评、严格跨班、禁止直接互评、初始班内负担差不超过一。

追加分配固定全部已有边，仅对新增作品建立候选边与二元变量。仍要求每份五评、严格跨班且与历史任务合并后不出现直接互评。目标首先最小化累计任务负担的平方和，再减少历史重复，最后按固定种子打破平局。增量阶段在不改旧任务的约束下优化负担，不要求追溯重排以恢复初次分配的负担差。

预览明确显示已有任务数与待新增任务数。快照包含已有分配边，参与名单或替补发生变化后需要重新确认。每轮分配有独立运行记录。人数或约束不可满足时不产生部分分配。
