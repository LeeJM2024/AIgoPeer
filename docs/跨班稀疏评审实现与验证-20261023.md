## 1. 已落地的规则

- 两班有效提交者参与：严格跨班，每份作品分配五名不同评委，初始班内负载差不超过一；两个方向联合求解，禁止本轮直接互评。
- 最近二十份相关历史作业用于减少重复配对；seed、输入快照、任务边和求解诊断写入运行记录。人数必要条件或求解失败均保留失败记录，不生成部分任务。
- 稀疏聚合只扫描实际评分，按方向与连通分量进行画像中心化；不足三份已评作品的评委保留先验，不将不足样本伪装成已学画像。
- 历史异常关系按不同作业累计证据，使用早于当前作业的历史；同一作业重算只取最新成功运行，不重复累计支持数。重复同向异常与持续正向环进入教师复核。
- 教师先预览名单和工作量，再确认快照并初始化；名单变化需重新确认。未完成任务可填写原因后替补，原任务、替补任务与操作历史均保留；已提交评分不允许替换或改写。
- 每份作品必须收齐五份完整有效评分才能正式聚合和发布。HIGH 复核展示初次教师分、五人评分、聚合分及异常证据，由同一位教师填写最终分和理由。
- 权限、任务统计、学生反馈和发布检查统一使用有效任务，停用任务不再给原评委开放。

替补可能改变初始负载分布，因此原分配均衡与替补后的实际负载分别记录，不将补评后的负载仍声称为严格初始均衡。

## 3. 教师操作顺序

1. 确认两个班的学生和作业配置，发布作业，学生完成真实提交并通过材料检查。
2. 提交截止后打开评审分配预览，核对参与名单、人数与负载，确认后初始化任务。
3. 学生完成自己的匿名评审任务；缺评时由教师填写原因并替补，继续等待有效评分收齐。
4. 教师完成初评并锁定，执行聚合，检查风险与证据；按风险流程处理或填写复核最终分。
5. 发布前检查通过后发布成绩；学生查看本人反馈与成绩，教师可导出成绩来源。

初始联合分配的必要条件为 `min(n1,n2) >= 5` 且 `5*(n1+n2) <= n1*n2`，最终以约束求解结果为准。这里人数指符合参与条件的提交者，不是班级花名册总人数。

## 5. 可复现模拟实验

脚本：[sparse_review.py](../algorithm/experiments/sparse_review.py)。原始结果：[cross-class-sparse.json](../output/experiments/cross-class-sparse.json)，保存版本、参数、种子、输入假设、各场景结果与诊断。

```powershell
$env:PYTHONPATH='backend'
.venv/Scripts/python.exe -m algorithm.experiments.sparse_review
```

覆盖 10∶10、100∶40、120∶40，各使用 41、42、43 三个种子。无历史与带历史两轮合计十八次联合分配全部成功，每份恰五评、班内负载差不超过一、直接互评数为零。100∶40 为 700 条任务和 8,000 个候选变量，120∶40 为 800 条任务和 9,600 个候选变量。

本次模拟中，有历史分配在 100∶40 和 120∶40 场景将历史重复率降至零；10∶10 受可行配对数量限制，仍有 28% 重复。比较对象为固定五人、简单跨班随机和仅负载均衡。上述数字仅对应输出文件中生成的历史，不外推为真实课堂比例。

模拟真分为 40～90 均匀分布，评委严宽偏差在班内中心化，原始偏差采样为 ±10，正常噪声标准差为 3。污染场景加入 10% 极端评分，并附带短时与短评语行为。九个场景等权汇总的 MAE 均值与标准差如下：

| 聚合方法 | 正常评分 MAE | 污染评分 MAE |
| --- | --- | --- |
| 平均分 | 1.955 ± 0.244 | 6.967 ± 0.667 |
| 中位数 | 2.700 ± 0.360 | 3.862 ± 0.956 |
| 去极值平均 | 2.315 ± 0.255 | 4.572 ± 0.737 |
| 稀疏贝叶斯 | 1.263 ± 0.171 | 2.147 ± 0.965 |

正常场景的任务级 HIGH 误报均为零；污染场景检出率随种子变化，完整 precision、recall 与 F1 保存在原始结果中。实验为合成数据下的工程验证，不是原论文复现或真实课堂效果结论。

### 实验推动的区间规则修正

100∶40 场景中，大班评委每人只评约两份，画像保留先验；五名先验评委产生的正常区间宽度约为满分的 21%。原 20% 判定线会使对方班正常作品批量进入 HIGH。

现增加 `prior_only_wide_interval_threshold=0.25`：仅在模型收敛、该项所有评委画像均未学习时启用 25% 判定线。其他场景和未收敛/小样本回退仍使用 20%。不改写实际区间，不伪造已学画像，不关闭四对一、后验离群、模型冲突或历史关系等其他 HIGH 条件。每项证据保存实际判定线，并在教师端展示。

本次正常场景区间覆盖率均为 1，区间偏保守，不能据此声称已完成 95% 区间校准。所有分配样本在结构交换前已经连通，因此这组实验也不证明结构交换带来了连通性提升；代码保留交换前后诊断，供后续更复杂输入比较。

## 6. 复杂度与交付状态

分配使用 SciPy/HiGHS 的 0–1 混合整数规划，最坏搜索复杂度为指数级，默认求解时间上限二十秒，仅接受最优完成状态；失败写入诊断，不降级为违反约束的任务。实测时间与模型规模在原始 JSON 中逐项保存。

聚合按实际观测而非完整评委×作品矩阵扫描，主迭代时间为 `O(I*M*K)`，其中 `I` 为迭代数、`M` 为实际任务数、`K` 为 Rubric 项数。历史关系分析采用最近二十份相关作业的窗口与有界长度环检测，其成本还取决于历史图的节点度数。
