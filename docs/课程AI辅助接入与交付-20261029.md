# 课程 AI 辅助接入与交付

## 功能入口

| 使用者 | 入口 | 功能 |
|---|---|---|
| 教师 | AI 辅助 → 文字助教 `/teacher/ai` | 配置全课程文字模型、测试连接、设置学生每日配额与编程辅导方式 |
| 教师 | AI 辅助 → 视频辅助评阅 `/teacher/ai?tab=video` | 配置独立的音视频模型；在作品材料区启动分析、查看逐项建议与时间点证据 |
| 学生 | 编程题 → 问助教 | 理解题目、解释当前代码或所选片段、结合本人判题版本分析错误、分析复杂度、获取提示 |
| 学生 | 知识点学习 `/student/knowledge` | 按章节或关键词查找课程知识点，讲解、举例、证明、比较与互动练习 |
| 教师 | 学习分析 → AI 教学建议 | 按当前班级范围，依据真实提交、错误分布和知识点统计安排讲解、复习与练习 |

## 教师首次配置

1. 打开「AI 辅助」，文字模型默认 Base URL 为 `https://api.deepseek.com`，模型名为 `deepseek-flash`；可以按自己的账户更换模型或兼容 Chat Completions 的 HTTPS 服务。
2. 填入老师自己的 API Key，点击「测试文字连接」。测试发送短消息，调用成功后仍需点击「保存配置」。
3. 设定每位学生每日提问次数，默认 30 次，可选 1–200 次。按北京时间自然日计数，已发送给模型但失败的请求也计入次数。教师每日上限 200 次。
4. 默认编程助教采用提示辅导方式。勾选「允许编程助教提供完整题解」后允许模型进一步提供完整实现。此选项控制助教提示策略。
5. 保存后密钥输入框清空；再次保存时留空可保留已有密钥。更换 Base URL 需要重新填写密钥。学生无需填写密钥。
6. 视频辅助评阅在独立标签页配置 Qwen-Omni 或 Gemini 音视频模型，详见《教师视频辅助评阅使用与实现-20261029.md》。普通文字模型用于上述三个文字助教。

## 对话和数据

- 文字密钥使用现有 Fernet 主密钥加密存储。备份数据库时同时保留 `storage/.private/video-ai.key`，该文件与真实 API Key 均不提交 Git。
- 课程当前为单教师设计，文字配置为课程级单例；视频配置按教师保存。
- 学生必须已加入课程班级。编程助教检查作业可见性与提交归属，只读取公开样例、当前编辑器代码及本人选定的判题版本；不读取隐藏测试用例或其他学生代码。
- 编程请求明确标记编辑器代码是否不同于已判题版本，避免将旧判题结果当成当前草稿的结果。选中片段必须存在于当前草稿中。
- 教学建议读取与学习分析页一致的班级统计，不发送学生身份、源代码或未发布的个人成绩。模型根据统计提出教学建议。
- 每次提问将对应材料和问题发送给老师配置的模型服务。页面在编程助教中明确提示代码发送行为。
- 对话按用户、模式和题目/知识点/班级范围隔离。重进页面恢复该上下文的最近一段对话，最多显示最近 30 轮；模型携带最近 6 个成功问答，重新构造当前上下文。
- 每位用户同一时间处理一个文字问题。刷新页面可轮询恢复进行中的请求；超过 10 分钟的未完成记录标记中断，可重新提问。
- 回答支持标题、正文、列表、行内代码与代码块复制；通过 Vue 文本插值渲染，不解释模型输出中的 HTML。
- 文字助教和视频建议独立保存，不修改判题结果、教师评分、同伴评分或最终成绩。

## 后端结构与 API

迁移 `20261029_0019` 建立 `course_text_ai_settings`、`text_ai_requests`，前置迁移为 `20261029_0018`。视频配置迁移为 `20261029_0017`。更新后端依赖后执行 `alembic upgrade head`。

| 方法 | `/api` 下路径 | 用途 |
|---|---|---|
| GET / PUT / DELETE | `/teacher/ai-text/settings` | 文字模型配置 |
| POST | `/teacher/ai-text/test` | 真实文字连接测试，测试不保存配置 |
| GET | `/student/ai/status` | 学生可用状态和配额，不含密钥和接口地址 |
| GET | `/student/ai/topics` | 课程知识点目录 |
| GET / POST | `/student/assignments/{id}/ai/history`、`.../messages` | 编程助教历史与提问 |
| GET / POST | `/student/ai/topics/{id}/history`、`.../messages` | 知识点助教历史与提问 |
| GET / POST | `/teacher/ai/teaching/history`、`.../messages` | 教学建议；可传 `class_id` |

`app/services/course_ai.py` 构造权限校验后的上下文、计数并保存请求；`text_ai_provider.py` 负责 Chat Completions 调用。复用现有 HTTPS 地址检查、密钥加密和错误脱敏。连接不跟随重定向，不将服务商原始错误正文返回页面。
