# 教师视频辅助评阅

## 页面使用

1. 登录教师账号，打开主导航「AI 辅助」，切换「视频辅助评阅」。地址 `/teacher/ai?tab=video`，旧地址 `/teacher/ai-video` 自动跳转。
2. 选择通义千问 Qwen-Omni 或 Google Gemini。页面提供默认模型与 Base URL；如服务商使用业务空间专属地址或代理，请填写对应的完整地址。
3. 填写自己的 API Key，点击「测试视频连接」。系统生成两秒带声音的视频进行实际音视频接口测试，产生少量调用费用，不发送学生材料。
4. 点击「保存配置」。保存后，API Key 输入框清空；以后留空表示使用已保存密钥。更换服务商或接口地址必须重新填写密钥。
5. 打开作业评分页，选择作品，在材料区域点击「分析视频」。系统使用该作品提交包 manifest 指定的视频和本作业评分表。
6. 页面展示进度、内容概述、逐项建议分、理由、模型自评置信度和时间点证据。点击时间点会打开原视频并定位到对应位置。
7. 教师结合材料填写评分。分析结果独立保存，不写入教师分、同伴分、风险复核或最终成绩。

关闭页面后，服务端继续分析；重新进入作品可查看进度与结果。可停止分析、重试或查看最近十次分析记录。删除密钥会停止该教师当前任务，保留历史结果。停止操作在当前模型调用结束后阻止后续结果保存，不保证撤销服务商已经接收的请求。

## 接口协议与处理

- 千问：Chat Completions，`video_url` Base64 输入、SSE 文本输出。模型必须支持同时理解视频画面和声音，例如页面预填的 `qwen3.5-omni-flash`。
- Gemini：原生 `generateContent`，`inline_data` 视频输入。页面预填 `gemini-3.8-flash`，模型名可修改。
- 自定义 Base URL 仍须实现所选服务商协议，并使用可访问的公网 HTTPS 地址。系统不跟随接口重定向。
- 视频最长 30 分钟，每 120 秒切片，覆盖全部时长。每段压缩到 720p 范围、5 fps，保留声音，限制 Base64 请求大小；对片段分别观察后按完整评分表汇总。
- 输出校验涵盖评分项完整性、分数上限、数值精度、置信度范围和证据时间范围；失败记录具体错误，不保存部分建议。
- 同作品同教师的活动任务去重，已有相同输入的成功结果可复用；明确点击重新分析会创建新任务。每位教师最多同时分析两个视频。
- 后台任务在单个 API 服务进程中运行，数据库保存状态、进度与结果。进程异常中断后可停止并重试；超过 90 分钟的活动任务在下次查询时标记中断。

## 配置与存储

- 教师配置独立存储在 `teacher_video_ai_settings`，API Key 使用 Fernet 加密；HTTP 响应不返回密钥或密文。
- 加密主密钥首次保存时自动生成于 `storage/.private/video-ai.key`，无需老师修改环境变量。部署备份须同时保留数据库和该文件。
- 视频在临时目录处理，请求完成后清理；模型错误响应正文不写入数据库或页面。
- 新迁移 `20261029_0017` 新增配置表及分析结果字段；使用项目更新后的依赖重新构建后端，再运行 `alembic upgrade head`。

## 主要 API

| 方法 | 路径（均以 `/api/teacher` 开头） | 作用 |
|---|---|---|
| GET / PUT / DELETE | `/ai-video/settings` | 读取、保存、删除本人配置 |
| POST | `/ai-video/test` | 用传入配置或已保存密钥测试音视频接口 |
| GET | `/submissions/{id}/video-analysis` | 最近十次本人分析记录 |
| POST | `/submissions/{id}/video-analysis` | 创建任务，`force` 控制是否重新分析 |
| POST | `/submissions/{id}/video-analysis/{run_id}/cancel` | 停止本人活动任务 |

所有接口仅教师可访问，作品相关操作沿用作业关闭、删除检查。

## 验证

新增后台测试覆盖两种服务商请求格式、错误隐藏、配置加密与隔离、完整分段、结果校验、任务复用、停止、失败落库，以及正式成绩表不被写入。前端测试覆盖保存与删除密钥、连接测试、切换服务商、进度轮询及时间点回看事件。

实际外部分析需由教师在页面填入有效密钥后进行。「测试视频连接」调用真实接口；自动化测试使用模拟模型响应。
