# 安全与隐私

AlgoPeer 围绕课程账号、作业材料、代码运行和成绩记录提供分层保护。学生、学生评委和教师通过各自的权限访问课程信息，关键评分操作保留过程记录。

## 账号与会话

学生账号由教师添加或导入，教师账号由课程管理员提供。账号输入统一处理全角与半角形式，并检查重复和不可见控制字符，减少相似账号造成的混淆。姓名保留正常中文表达，过滤会破坏材料路径或页面显示的控制字符。

密码使用带盐的 scrypt 哈希保存。修改密码需要验证当前密码，新密码长度为 10～128 位；成功后旧会话撤销，当前设备换发新会话。退出登录会撤销对应服务端会话。

服务端同时校验登录令牌的签名、有效期、签发方、受众和会话状态。登录失败使用统一提示，并分别按账号和来源地址限制频率：账号 10 次 / 10 分钟、来源 IP 60 次 / 分钟。

## 谁可以看到什么

| 使用者 | 可以访问的课程信息 |
| --- | --- |
| 学生 | 本人可见的作业、本人提交及历史、本人已发布成绩与反馈 |
| 学生评委 | 系统分配给本人的有效任务及对应匿名材料、本人评分与可修改窗口 |
| 教师 | 课程班级、作业材料、提交历史、原始评分、异常证据、复核与成绩统计 |
| 课程管理员 | 部署配置、服务器与备份，根据学校管理安排维护服务 |

服务端逐次检查角色、班级、提交归属和评委任务归属。知道某个编号或材料地址，仍需通过对应权限检查。任务被替补停用、作业关闭或删除后，访问能力按当前状态更新。

## 匿名材料

学生评委通过任务匿名编号获取材料。系统处理文件名和可处理的元数据，将匿名材料与教师读取的原始材料区分保存；学生查看发布反馈时使用汇总信息。

匿名评阅同时需要作者处理正文中的身份线索：上传前检查 PPT、视频画面与口述、README、代码注释和文件内容，移除姓名、学号和联系方式。教师仍可以查看原始归属，以完成评分、复核和课程管理。

## 上传文件的检查

期末材料以 ZIP 提交，最大 500 MiB。服务端在身份、作业与频率检查后处理材料，并检查实际请求大小。

| 材料 | 检查与处理 |
| --- | --- |
| ZIP 路径 | 拒绝绝对路径、目录穿越、盘符、符号链接、重复或同形路径 |
| ZIP 结构 | 检查文件数量、解压后体积和异常压缩比，拒绝加密包 |
| PPTX 等 Office 内容 | 检查内层压缩结构，拒绝宏、ActiveX、嵌入对象和外部关系等内容 |
| 图片 | 限制像素数量，识别异常素材 |
| 视频 | 处理工具限制输入协议，读取 MP4 时使用固定解复用器；提取和分析在临时目录完成 |
| 材料清单 | 核对必交文件、例题、源码及输入输出测试的相对路径 |

自动完整性检查确认文件结构与必要材料是否齐备。内容正确性、讲解质量和课程要求由教师与评委结合评分标准评阅。

## C++ 程序怎样执行

学生提交的 C++17 程序由判题 worker 调度到隔离容器：关闭网络、使用非 root 身份、根目录只读、移除容器能力并禁止提权。每次提交使用独立的工作身份和私有目录。

编译和运行限制 CPU、时间、内存、进程数、文件描述符及输出量。worker 读取结果时拒绝符号链接和命名管道，并在用例之间清理可能被学生修改的输入输出文件。

正式部署将判题节点与应用、数据库和密钥所在主机分开，Docker 控制权限只交给判题 worker。配置方法见[部署与运维](部署与运维.md)。

## 请求与浏览器保护

前端为写操作自动附加时间戳和一次性随机编号。同一会话中的编号只消费一次，服务端检查时间窗口并阻止相同请求的并发重放。设备时间偏差过大时，校准时间后即可重新操作。

系统还限制整体请求、写操作、材料上传和代码提交频率。默认每用户 600 请求 / 分钟、120 写操作 / 分钟，ZIP 上传 10 次 / 10 分钟，代码提交 10 次 / 分钟。

部署通过 HTTPS 域名提供服务。后端检查可信 Host、写操作来源和允许的跨域来源；浏览器策略限制脚本来源、插件、页面嵌入与来源信息泄漏。AI 回答按受控 Markdown 与公式渲染，普通文本和代码转义显示，模型提供的 HTML 作为文本处理。

## 评分与成绩记录

教师初评分、评分更正、同伴评分版本、算法运行和最终复核分分别保存。评分锁定、作业权重冻结、发布检查与历史保护同时由服务端和数据库约束落实。

高风险复核展示第一次教师分、五人原始分、聚合结果和异常证据；教师确定复核最终分后保存。AI 辅助结果独立记录，正式评分由教师与评审流程写入。

删除作业会从正常访问入口移除，底层业务与审计记录继续保留。部署方按照学校的课程数据管理要求制定备份、保存期限与后续归档安排。

## AI 服务使用的数据

使用 AI 时，相应问题与必要上下文会发送给教师配置的外部模型服务：

| 场景 | 发送的上下文 |
| --- | --- |
| 编程辅导 | 题目、公开样例、当前代码或选中片段、本人所选判题版本及反馈 |
| 知识点学习 | 选定知识点、问题及当前上下文中的相关对话 |
| 教学建议 | 当前班级范围内的课程统计；不发送学生身份、源码或未发布的个人成绩 |
| 视频辅助评阅 | 当前作品视频片段（含声音）、本次作业评分表及分析提示 |

编程辅导只读取公开样例与本人版本，隐藏测试和其他学生代码保持隔离。教师选择模型服务时，应结合课程数据使用要求了解服务商的保存与处理政策；视频中的声音和画面也属于发送内容。

模型密钥在服务器加密保存，学生无需填写密钥。配置接口不返回原始密钥或密文，保存后页面清空密钥输入框。加密主密钥存放在私有存储目录，备份时与数据库配套保存，并由部署管理员控制访问。

各项 AI 的使用方法见[AI 辅助特色](AI辅助特色.md)。

## 课程成员的日常操作

使用个人账号，首次登录后修改初始密码；完成公共电脑上的操作后退出登录。上传前处理身份线索，核对材料路径和当前版本。遇到权限、材料或成绩问题时，将作业编号、提交编号与页面提示交给教师，便于查找对应记录。
