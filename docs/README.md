## 三类作业流程

| 作业类型 | 学生完成方式 | 结果 |
| --- | --- | --- |
| 编程题 | 在线提交 C++17 代码 | 自动判题和提交历史 |
| 算法分析、证明、开放问答 | 在线填写文本答案 | 提交即完成；教师查看答案与历史 |
| 期末微课 | 选题并上传 ZIP 材料包 | 材料检查、跨班五人评审、教师评分与复核、成绩发布 |

期末微课以两个班为评审范围。其他题型可以面向一个或多个班级。系统按作业类型提供对应操作。

## 成绩与责任

期末微课默认采用教师初评分 60% 与同伴聚合分 40% 的成绩组成，具体比例以教师发布作业时的设置为准。高风险作品进入教师最终复核。AI 为学习和评阅提供建议，正式成绩由课程评分流程产生。

算法的数学表达、默认阈值和输入输出见[算法实现规格](../algorithm/ALGORITHM_SPEC.md)；需要试用上传时可使用[材料样例](../samples/README.md)。
