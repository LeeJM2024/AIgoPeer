# 前端「算法演算场」实现记录

## 本轮范围

在 `feat/frontend-devise` 上实现用户已批准的蓝白渐变、大弧角、算法与代码插画方向。没有切换分支、拉取、提交或推送；没有改动后端、数据库、接口契约或运行依赖清单。

已调整登录/注册外观、公共导航、学生首页、教师首页、教师作业列表、学生编程与项目提交页、教师评分材料/表单布局及统一主题。其他内页复用新主题，没有重写其业务流程。

## 视觉与交互

- 登录不对称构图，真实表单不再被一张大宣传卡片包住。
- 原生 SVG 演示四项数组的稳定归并排序；真实递归、比较、归并驱动数字位置与代码行。代码为片段，明确省略 merge 实现。
- 暂停、步进、重播；离屏/文档隐藏时暂停；减少动态效果下不自动播放，仍可手动查看步骤；卸载清理定时器和监听。
- 归并、动态规划、图、树、整数求和、微课材料与一般代码使用不同主题插画，不突出五人协作评审。不请求外部图片服务。
- 学生默认展开最近截止的待处理作业，剩余列表不重复；搜索/筛选时回归完整匹配列表。材料检查未通过的开放项目保留在待办中。这里只调整视觉优先级，后端权限仍为准。
- 教师待办在最近作业之前，深色侧栏只展示一份实际作业，不重复课程宣传横幅。
- 编程题目与编辑器并排；教师材料与评分并排，窄屏按内容顺序堆叠。预览区保留真实提交文件/视频入口。

登录源码 lint 为 0 FAIL / 0 WARN。浏览器检查针对已批准方向使用明确例外 `gradient,button-fx,few-pictures`：
