## 4. 原始证据组织

建议目录（按需建立，不要求无用文件）：

```text
tmp/verification/<run-id>/
  manifest.md
  ledger.md
  objects.md
  compose.verify.yml       # 本轮私有配置
  .env.verify              # 私有凭据，不公开
  fixtures/                # 合成材料与哈希
  auto/                    # pytest.xml、测试/构建输出及 skip 分析
  api/                     # 去认证头/去敏感字段的请求响应
  browser/                 # 截图、必要录屏、视口与对象索引
  judge/                   # 提交/队列/worker/容器关联证据
  media/                   # ffmpeg、匿名包清单、元数据与人工核查
  database/                # 只读对账、事务前后不变量
  defects/                 # 缺陷与修复复验
  final-report.md
```

截图文件建议 `<用例ID>-<对象逻辑名>-<状态>-<视口>.png`。API 记录可包含请求方法、路径、去密钥的请求体、状态码、业务码、响应字段；保留对象关联信息。认证响应保存时去除完整令牌。容器日志先检查是否含密钥。

每条闭环以对象链串联：作业 → 作者提交各版 → 当前材料检查/匿名包 → Panel/五人任务 → 评分 → algorithm_run → 教师评分版本/锁定 → 异常处理/复核 → final_grade → 学生反馈/教师导出。截图只有“成功”提示而没有对象链，不足以证明闭环。
