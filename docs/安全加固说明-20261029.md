# AlgoPeer 安全加固

## 已实现的控制

| 入口 | 控制 |
| --- | --- |
| 账号 | 登录和教师导入均使用 NFKC 规范化全角/半角；只接受 ASCII 字母、数字、`_.@-`；规范化后检测批量重复；拒绝零宽字符与双向控制字符 |
| 姓名 | 拒绝控制字符和能构造危险上传文件名的字符；正常中文姓名保留 |
| 密码、代码和答案 | 保留原文，避免规范化改变密码或程序语义；密码用 scrypt 加盐哈希；验证失败不回显输入 |
| 登录 | 账号 10 次/10 分钟、来源 IP 60 次/分钟；持久化限速；不存在账号也执行密码哈希验证；错误信息统一 |
| 会话 | JWT 校验签名、签发方、受众、过期时间及服务端会话；退出立即撤销；改密撤销所有旧令牌并为当前设备换发令牌；管理员直接重置密码也会使旧会话失效 |
| 写请求 | `X-Request-Timestamp` 使用秒级 Unix 时间；允许过去 300 秒、未来 30 秒；`X-Request-Nonce` 为 16 个随机字节的十六进制字符串；同一会话下原子消费，只允许一次，包括业务失败和并发重放 |
| 操作频率 | 每用户 600 请求/分钟、120 写操作/分钟、10 次作业 ZIP 上传/10 分钟、10 次编程提交/分钟；跨进程共用数据库计数 |
| 浏览器 | Vue 文本插值保留自动转义；CSP 禁止行内脚本、插件和任意站点脚本；禁止页面被嵌入；nosniff、无来源泄漏、接口禁止缓存 |
| 跨站与越权 | 校验可信 Host 和写操作 Origin；CORS 只允许配置来源；API 不使用浏览器自动附带的 Cookie；保留教师、学生、提交所有者、评委任务归属校验 |
| 请求体 | JSON 等普通请求最多 8 MiB；项目 ZIP 最多 500 MiB 加 1 MiB multipart 开销；同时检查 Content-Length 和实际流量；ZIP 在认证、频率和课程权限检查后才解析，只允许一个文件和一个清单字段 |
| ZIP | 不落盘解压；拒绝路径穿越、全角路径绕过、盘符、符号链接、加密 ZIP、重复/同形路径、异常压缩比和超限文件数量/解压体积 |
| PPTX 等 Office | 内层 ZIP 单独限制为总计 128 MiB、单项 32 MiB；拒绝宏、ActiveX、嵌入对象、外部关系、DTD 和实体；内存读取的材料最多 64 MiB |
| 媒体 | 图片最多 2000 万像素；视频工具限制输入协议，分析 MP4 固定使用 MOV 解复用器，禁止通过视频访问网络；素材异常只返回通用错误 |
| C++ 判题 | 断网、只读根目录、非 root、丢弃全部 capabilities、禁止提权；按提交分配 UID 与私有目录；限制进程/内存/CPU/文件描述符/日志/编译输出；worker 读文件拒绝符号链接、FIFO，下一测试前移除可被学生篡改的输入输出文件 |
| 生产配置 | HTTPS 来源、独立强密钥校验；隐藏 API 文档；只读容器、持久化材料卷、临时目录和并发上限；数据库/Redis 不向公网发布 |
| 依赖 | 升级存在已知漏洞的 FastAPI/Starlette、Pillow、cryptography、Vite/Vitest 等；使用 npm audit、pip-audit 检查 |

一次性编号拦截捕获请求的原样重放和重复提交。持有有效密码或令牌的人仍能生成新请求，因此正式部署必须使用 HTTPS，并及时修改初始密码。请求失败后前端重新操作会生成新编号；服务端不自动重试写操作。

## 本次升级后的使用

迁移 `20261029_0018` 只增加会话和请求编号表，不删除学生、班级、作业、提交或评分。旧版令牌没有服务端会话，升级后需要重新登录一次。

前端自动提供时间戳和随机编号，正常操作无需额外填写。脚本调用写接口也需要携带这两个请求头。设备时间偏差超过容许范围会提示校准。

## 正式部署

1. 使用域名和有效 TLS 证书，通过反向代理提供构建后的 `frontend/dist`，同源代理 `/api`；不要向同学开放 Vite 开发服务器。
2. 设置 `APP_ENV=production`、`CORS_ORIGINS=https://你的域名`、独立随机 `JWT_SECRET` 和 `INTERNAL_API_TOKEN`；使用私有数据库密码。生产 compose 已强制要求这些值。
3. 根据实际网络配置 `TRUSTED_PROXY_IPS`，仅信任反向代理的源 IP；不能设为 `*`。否则登录限速会把所有用户视为同一个代理 IP。
4. 反向代理限制请求大小和连接数，并发送 `X-Frame-Options: DENY`、`X-Content-Type-Options: nosniff`、`Referrer-Policy: no-referrer` 和 `Strict-Transport-Security: max-age=31536000`。构建 HTML 已携带 CSP，反向代理可以追加 `frame-ancestors 'none'`。
5. 判题 worker 的 Docker socket 只授予 worker。面向真实不可信代码时将判题节点单独部署；应用、数据库和密钥不放在判题节点上。
6. 首次登录后修改教师及学生的共享初始密码；备份数据库、材料卷和 `storage/.private/video-ai.key`，该目录禁止作为静态文件服务。

## 验证

安全回归位于 `tests/backend/test_security_hardening.py`，覆盖账号规范化、跨站请求、可信 Host、请求大小、并发重放、失败请求重放、改密/退出撤销、学生越权、ZIP 路径和 Office 内容。数据库测试使用随机隔离 schema。

前端回归覆盖请求随机编号、重定向与凭据策略、危险 URL 拦截和标题 XSS 文本呈现。既有评分、材料和匿名评阅测试验证业务兼容性。
